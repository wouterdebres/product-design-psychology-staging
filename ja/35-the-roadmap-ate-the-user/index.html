ロードマップがユーザーを飲み込んだ

うまくいかないと知りながら、つくり続ける理由

ロードマップは計画であることをやめ、奉仕する相手になった。

その切り替わりは、見落としやすい。起きている最中には、責任ある行動に聞こえる。チームは、ユーザーに何が必要かを問うのをやめ、3回前の計画会議で約束したことをどう守るかを問い始める。

ここでの話は、計画そのものへの執着だ。日程、範囲、節目、すでにした約束。あとから得られたユーザーの証拠より、ロードマップのほうが、会議で重みを持ち始める。

約束が、代わりに考え始める

Barry Staw は1976年、コミットメントのエスカレーションを説明した。以前の決定に責任を感じる人は、状況が悪くなったあと、さらに多くの資源を投入した。彼は「人は、悪い結果について自分に責任があるとき、以前に選んだ行動方針に最も多くの資源を投入した」（英語からの翻訳）と書いている。

会社のなかで、ロードマップはそういうものになりうる。大まかな見立てではなく、皆の前で交わした約束の連なりに感じられるようになる。そうなると、方向転換は、プロダクトについて学んだ結果とは感じられない。失敗に感じられる。

ここで Kahneman と計画錯誤（planning fallacy）が関わるのは、計画にはいつも、根拠のない確信がついてくるからだ。チームは、仕事がどう進むはずかを思い描く。同じような仕事が普段どう進むかに照らして、判断しない。ロードマップは、過剰な自信から始まり、やがて現実そのものであるかのように守られる。

だから、ロードマップの言葉は、すぐに危険になる。日程や節目が書かれると、暫定的には聞こえなくなる。裏づけのあるもののように聞こえ始める。チームは、以前の状況のもとで立てた推測だったことを忘れ、未来のほうが従う義務を負っているかのように扱い始める。

FBIは、プロジェクトに仕え続けた

FBIは、Virtual Case File プロジェクトに5年と1億7000万ドルを費やした。技術者が問題を警告した。外部の評価者も問題を警告した。証拠は届き続けた。それでも、プロジェクトは進み続けた。2005年4月、FBIは、一度も運用しないまま打ち切った。

この事例が重要なのは、そこだ。価値が急にはっきりしたから、続いたのではない。計画、お金、政治的な重み、組織としての自己像が、やり遂げることにすでに結びついていたから、続いた。

ロードマップは、古い約束を、新しい圧力に変え続けることがある。

ほとんどのプロダクトチームは、そこまで大きなプロジェクトを運営しない。仕組みは、もっと小さな会議室でも同じだ。計画で機能が発表される。営業が聞く。マーケティングが資料に載せる。経営陣がレビューで日程を繰り返す。そこに新しいユーザーの証拠が届いても、その約束をいったん取り下げようと言う役には、誰もなりたくない。

そのとき機能は、問題への対応であることをやめ、チームを縛る約束になる。そう切り替わると、方向転換は、賢明な判断ではなく、裏切りのように聞こえ始める。

計画が固まると、何が消えるのか

ロードマップが固まると、ユーザーの問題は、会話から薄れていく。

「これをまだつくるべきか」と問うのをやめ、「どうすれば第3四半期に間に合うか」と問い始める。機能が正しい答えかを問うのをやめ、どんな形の機能なら期日までに実現できるかを問い始める。内側の視点（inside view）が支配する。チームは計画を細かく知っている。そのため、あとから届いたユーザーの手がかりより、計画のほうが現実味を帯びてくる。

その機能は弱いと全員がわかっているのに、納期に間に合うかというリスクの話しかしないチームを、私は見てきた。その時点で、ロードマップはすでに勝っている。

ここでは、言葉にも本音が出る。「約束を守らなければ」「ここまで進んだら、範囲を蒸し返せない」。規律があるように聞こえる。ときには、事実が変わったあとも、計画を守っているだけだ。

何を問い直すか

進捗報告ではない会議を、一つ予定に入れよう。そこで、問題そのものをもう一度問う。

問いは単純でいい。今わかっていることを知ったうえで、今日から始めるなら、これはまだロードマップに載るだろうか。「予定どおりか」ではない。それは、計画への忠実さを測るだけだ。その約束は、まだ残すに値するかを問う。

答えがノーなら、ロードマップを変える。ぶれているのではない。それが仕事だ。

「わからない」なら、その曖昧さを表に出そう。あまりにも多くのロードマップレビューが、進捗報告から、そのまま安心の確認へ飛ぶ。役に立つ会議は、不確実さの周りにさらに仕事が積み固まる前に、それを見えるようにする会議だ。

「2週間前より、確信が持てなくなっています」と言うだけで場が緊張するなら、ロードマップはすでに強くなりすぎている。私も、そんな会議にいた。誰かが言い終わる前から、空気が張り詰めるのがわかる。

約束がどの四半期になされたかを、ユーザーは気にしない。出会うのは、世に出たものだけだ。
